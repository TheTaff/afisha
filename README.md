# Афиша

Учебный проект: вёрстка сайта концертно-экскурсионных программ по макету из Figma.

**Сайт:** https://thetaff.github.io/afisha/

## Что сделано
- Главная страница: шапка, слайдер, афиша, новости, календарь экскурсий, анонсы, подвал
- Афиша: список мероприятий
- Страница мероприятия: описание, программа, цена
- Контакты: адрес, телефоны, режим работы, карта

## Технологии
HTML и CSS

## Структура
```
index.html     - главная страница
afisha.html    - афиша
event.html     - страница мероприятия
contacts.html  - контакты
style.css      - стили
image/         - картинки и иконки
```
